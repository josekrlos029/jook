# Jook Agencia · jookagencia.com

Landing page de Jook Agencia. Sitio estático (un solo `index.html`), sin build.

## Archivos
- `index.html`: la página completa (estilos, logo vectorial y scripts incluidos).
- `favicon.svg`: símbolo de los dos nodos.
- `robots.txt` y `sitemap.xml`: indexación en buscadores.
- `vercel.json`: URLs limpias y cabeceras de seguridad.

## Despliegue
Conectado a Vercel: cada push a `main` publica a producción.
Framework preset: **Other**. Build command: vacío. Output directory: raíz (`.`).

## Pendientes
- Confirmar el correo `hola@jookagencia.com` (está en el HTML y en los datos estructurados).
- Confirmar la URL de Facebook (`facebook.com/jookagencia`).
- Registrar el dominio en Google Search Console y enviar `sitemap.xml`.
